GURUKARTHICK P — PERSONAL PORTFOLIO

Files
- index.html: page structure and portfolio content
- style.css: responsive layout, colour palette, animations
- script.js: mobile navigation, scroll effects, active section and footer year
- my-photo.jpg: add your own portrait using this exact filename

Run locally
1. Extract the ZIP.
2. Copy your photo into this folder and name it my-photo.jpg.
3. Open index.html in Chrome, Edge, Firefox or another modern browser.

No framework, package manager, server or build step is required.
The Google Fonts import is optional; the page has fallback fonts if offline.

Editing notes
- Update text directly in index.html.
- Change the colour variables near the top of style.css.
- The Python, Java and C progress bars are illustrative visual indicators only,
  not measured proficiency ratings.
- Contact links use mailto: and tel:.
- All supplied resume details are presented without adding work experience
  or unverified credentials.
